## Run and diagnose safely

- Repo: `hermes-agent-project`; current branch `main`. **The handoff first landed alone in `f64a1b0`; the subsequent implementation commit includes the source and older docs. A fresh clone has the source, but not the ignored live `poc/data/` state, credentials, or host containers. Check local Git and runtime state before changing anything.** Check `git status --short` first.
- Live container: `pilot-agent`; retained rollback containers: `pilot-agent-pre-quota` (immediately before quota), `pilot-agent-rollback` (before sandbox pilot). The quota cutover script is `poc/scripts/enable-model-quota.py`; `rollback` restores the former container and two profile configs. Inspect what changed before invoking it. `docker restart` reloads mounted source/policy but does not load changed `--env-file` values; env changes require container recreation.
- Host broker: `http://127.0.0.1:8787/health` with its local token; gateway: `http://127.0.0.1:8642/health`; quota proxy is **container-loopback only** at `http://127.0.0.1:8791/health`. The gateway launcher checks broker/tool policy and quota route before Hermes starts. No Docker daemon socket is mounted into the gateway or workers.
- Safe, read-only reports: `python3 poc/scripts/report-request-usage.py --hours 24 --json` (physical calls) and `python3 poc/scripts/report-usage.py --json` (lifetime Hermes sessions). Query SQLite with `mode=ro` and only IDs, scopes, counts, usage, and status. Data under `poc/data/` and `.env` contain private operational state. Avoid dumping Docker env, Slack messages, prompts, response bodies, or whole logs. Use `docker inspect` with narrowly selected fields; Docker access may require sandbox escalation.
- Main code: `poc/plugins/pilot-usage/` signs/records requests, `poc/usage/` enforces quotas, `poc/plugins/pilot-slack-controls/usage_limits.py` posts preflight refusals, and `poc/scripts/run-gateway-with-boundary.py` supervises proxy plus gateway. `poc/data/operator/quota-lib/` and live profile plugin folders are staged runtime copies. Changes to source alone do not change the running gateway; synchronize copies, restart, and verify health and a bounded model call.
- Useful tests: `python3 -m unittest poc.tests.test_model_proxy poc.tests.test_quota poc.tests.test_boundary_launcher` (needs local loopback socket permission) and `python3 poc/tests/pilot-slack-controls/test_usage_limits.py`. Also run `git diff --check`. Keep tests narrow and preserve the live rollback.
